## Integer-Division Tests (xfail)

The two tests `TestNetwork::test_update_mini_batch_int_eta` and
`TestNetwork2::test_update_mini_batch_int_eta` are marked:

```python
@pytest.mark.xfail(sys.version_info >= (3,), strict=True, reason=...)
```

On Python 3 (both legacy and modernised), these tests are **expected to fail** because
the golden values were captured on Python 2.7 with floor-division semantics (`3/2 == 1`),
while Python 3's true division produces `3/2 == 1.5`. The modernisation task specifies
**intentional true-division behaviour** and instructs that the float-eta tests must
match exactly. The int-eta xfail tests remain as-is, documenting the known semantic
difference between Python 2 and Python 3. They do not represent broken code.
