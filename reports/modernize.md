## Integer Division — Intentional Behaviour Change

Per the task specification, `eta/len(mini_batch)` uses **true division** (Python 3 default).
This is an intentional, documented semantic change:

| Runtime | `eta=3`, `batch_size=2` | Result |
|---------|------------------------|--------|
| Python 2.7 (legacy) | `3 / 2` | `1` (floor division) |
| Python 3.12 (modernised) | `3 / 2` | `1.5` (true division) |

The characterization tests for `float` eta (`test_update_mini_batch_float_eta`) pass
identically — floating-point division was already correct in Python 2 when `eta` was a
`float`. The integer-eta tests are marked `xfail(strict=True)` on Python 3 and correctly
record `XFAIL`.
